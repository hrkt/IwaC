# IwaC 進捗（できていること）

## 2026-11-01: v0 — 一番小さいバイナリが出て、動いた

- リポジトリを用意した: `~/workspace/iwac/iwac/`
  （GitHub は https://github.com/hrkt/IwaC ）
  ワークスペースの構成と理由は `doc/environment.md`
- `iwac.c` v0 を実装（当面は1ファイル）:
  - 入力は引数で渡すプログラム文字列: 1文字、または 10進数 0..255
  - 出力は RISC-V (rv64i) 生バイナリ 16バイト、命令4つ
    （`lui t0,0x10000` / `addi t1,zero,code` / `sb t1,0(t0)` / `wfi`）
  - UART (NS16550A、ベース `0x10000000`) へ1バイト書いて止まる
- 検証（`./test.sh` で再現できる内容）:
  - gcc 13.3.0 で警告なしビルド
  - `iwac A` と `iwac 65` の出力がバイト単位で一致、サイズは16
  - 逆アセンブルが想定の4命令と一致
    （`lui t0,0x10000` / `li t1,65` / `sb t1,0(t0)` / `wfi`）
  - QEMU virt で実行し、シリアルログの最後の1バイトが
    入力通り `A` / `B` になった。A用とB用のログは
    その最後の1バイトだけが違った（OpenSBI の表示部分は同一）
    ＝ 出ている文字が本当にこのバイナリ由来だと確認できた
- 未確認・意図的にやっていないこと:
  - UART 送信ポーリング無し（QEMU での第一歩として省略。実機向けの課題）
  - UART 初期化（分周比など）無し（同上、QEMU のデフォルトで動作）

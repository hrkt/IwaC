# オブジェクトの ELF 化: 形式 version 2 の設計

現行のオブジェクト形式 (.iwo、doc/object-format.md)
はテキストで、iwac と nori の間だけで通用する。
これを ELF の ET_REL (再配置可能オブジェクト) に
替えるのが、分割コンパイルの階段
(doc/linking.md) の最後の挑戦である。この文書は
その対応付けを設計として書き切る (2026-11-07、
設計のみ。実装はまだ)。

得られるもの:

- 標準の道具で読める: readelf / objdump で
  オブジェクトの中身が確かめられる (いまは
  自分たちにしか読めない)
- 「リンクとは何か」の標準形に触れる: セクション、
  シンボル表、再配置表という、本物の道具が
  使っている仕組みそのものになる
- 将来、実ターゲットの本物のローダやリンカと
  繋ぐときの土台になる

目指さないもの:

- GNU ld でそのままリンクできること。nori が
  読む前提の部分集合でよい。ただし ELF としての
  構造は正しく作る (道具で読めることが物差し)。
  doc/linking.md は当初「GNU ld でリンクして
  nori と比べる物差し」を得られるものに挙げて
  いたが、入口の接頭辞の運び方と callopt の
  「消える呼び出し」は ld の仕組みに無いので、
  物差しは「.iwo 経由との最終一致」に置き直す
- デバッグ情報 (DWARF)。入れない

## 全体

- ELF64、リトルエンディアン、ET_REL、
  e_machine = EM_RISCV (243)
- セクション: .text (コード)、.data (初期値の
  あるグローバルの実体)、.bss (初期値のない
  グローバルと配列の領域)、.iwac.strings
  (文字列の実体)、.symtab / .strtab /
  .shstrtab、再配置は .rela.text と .rela.data
- 配置 (アドレスの決定) は今までどおり nori の
  仕事で、規則は現行と同一にする: 入口の接頭辞を
  先頭に、関数本体は登録順、データは
  文字列 → 配列 → グローバルの順。最終の ELF が
  .iwo 経由とバイト一致することが物差し

## 対応表 (.iwo の各レコードが ELF で何になるか)

- `entry <長さ>`: 特別なシンボル **iwac_entry**
  で表す。.text のオフセット 0 に置き、size に
  接頭辞の長さを入れる。これを持つオブジェクトが
  入口で、nori は現行どおり接頭辞を先頭へ運ぶ。
  ET_REL に「入口」という概念はないので、
  名前の約束で持ち出す (iwac 専用の印)
- `func <名前> <位置> <大きさ>`: .text の
  STT_FUNC シンボル (位置と大きさはそのまま)
- `decl` / `undef <名前>`: 未定義シンボル
- `var <名前> <枠数>` (確定定義): 初期値があれば
  .data、無ければ .bss のシンボル。大きさは
  枠数 × 8
- `varc` (仮定義): **SHN_COMMON** のシンボル
  (alignment 8、大きさは枠数 × 8)。「仮定義は
  合体する」という現行の規則は、ELF の COMMON の
  意味そのものなので、形がぴったり合う
- `arr <名前> <位置> <バイト数>`: .bss の
  シンボル。位置はセクションの中での置き場で持ち、
  最終配置は現行の規則 (全オブジェクトの配列を
  まとめて文字列の後ろ) を nori が再現する
- `strings <バイト数>` と実体: .iwac.strings
  セクションの中身。文字列1つ1つはシンボルに
  しない (現行どおり名前がない)
- `init <名前> <値>`: .data の中身として
  そのまま入る (独立したレコードはなくなる)
- `iptr <名前> str <位置>`: .data への再配置
  R_RISCV_64。相手は .iwac.strings の
  セクションシンボル + addend (文字列の位置)
- `call <位置> <名前>`: .text への再配置
  **R_RISCV_JAL**。届く範囲 (±1MB) の検査は
  現行どおり nori の仕事
- `callopt <位置> kosaba_flush`: 相手を
  **弱い未定義シンボル (STB_WEAK)** にした
  R_RISCV_JAL。「定義がなければ呼び出しごと
  消える」は、弱いシンボルが未解決のまま
  残ったら nori が nop にする、と決めて表す。
  現行の意味 (宣言だけでも形を残す) が
  弱シンボルの意味とそのまま重なる
- `addr <位置> var/arr <名前>` (auipc + addi の
  組): auipc 側に **R_RISCV_PCREL_HI20**、
  addi 側に **R_RISCV_PCREL_LO12_I**。LO 側の
  相手は「組の auipc を指すローカルシンボル」
  (本物の ELF の作法どおり、組ごとに1つ作る)。
  addend は 0 (現行と同じ割り切り)
- `addrstr <位置> <文字列の位置>`: 組の作りは
  addr と同じで、HI20 の相手が .iwac.strings の
  セクションシンボル + addend になる
- `addabs <位置> <絶対アドレス>`: 絶対アドレスを
  値に持つ **SHN_ABS のローカルシンボル** を
  値ごとに1つ作り、HI20 / LO12_I の組で指す
  (相手が絶対なので PCREL ではなく通常の
  R_RISCV_HI20 / R_RISCV_LO12_I)
- `target kosaba` の行と `iwacobj 1` の題字:
  ELF ヘッダが代わりをする (対象は e_machine と
  オブジェクトの出自で分かる)

## 仕事の分担

- iwac: ELF を書く出口を1つ足す (材料は
  write_object と共有し、書き手だけ替える)。
  フラグの名前は実装のときに決める
- Asari: 出力は当面 .iwo のままにする。
  受け渡し (.ias) は変わらないので、ELF 化は
  iwac と nori の間で閉じる。Asari の追随は
  後でよい
- nori: ELF の読みを足す (ヘッダ、セクション、
  シンボル表、再配置表)。入力の判別は先頭の
  マジックで。当面は .iwo と ELF の両対応にし、
  レイアウトと穴埋めは共通の内側を使う
- mini_nori (test.sh の参照リンカ): 物差し役は
  当面 .iwo のまま。ELF の検証は readelf と
  「.iwo 経由との最終一致」が担う

## 実装の段取り

1. iwac の ELF 書き手。検証は readelf で構造を
   読み、.iwo と同じ材料から出ていることを
   セクションとシンボルの一覧で比べる
2. nori の ELF 読み。物差し: 同じ入力集合で、
   ELF 経由の最終 ELF が .iwo 経由とバイト一致
3. test.sh と Misoni の標準経路を ELF に
   切り替える
4. .iwo の引退は最後に判断する (形式に互換義務は
   ないが、mini_nori と Asari がまだ使う)

## 決めなかったこと

- 関数ごとのセクション分割 (.text.<関数名>) は
  しない。配置の登録順が iwac の約束なので、
  .text は1本に保つ
- 再配置の addend は、当面は現行と同じく 0 か
  セクション内の位置だけを使う。式の形の
  addend は持ち込まない

## 実装の記録 (v39、2026-11-07、branch `elfobj`)

手順1〜3を実装した (手順4の .iwo 引退は未決定。
mini_nori と Asari がまだ .iwo を使う)。
iwac 側は write_elf_object (新しい表は足さず、
シンボルの数え直しで組み立てる)、nori 側は
read_object_elf (マジックで振り分け、.iwo と
混在リンク可)。物差しは全コーパスで合格:
分割 (.eo) リンク = 分割 (.iwo) リンク =
一括 ELF (iwac 本体・hello・構造体・初期値)、
nori / Asari の単体 TU は .eo リンク = .iwo
リンク (入口断片が kosaba_flush を宣言しない
TU は、従来どおり一括版と入口の形が違う。
decls.c の kosaba_flush のコメント参照)。

実装中に踏んだ上限が一つ。命令表 40960 に
対し一括セルフコンパイルが約 44,500 命令へ
育ち、asm_push が無言で表の外へ書いていた。
点検を付け、表を 49152 に増量し、対価は
op / rd / rs1 / rs2 の char 化で払った
(静的データは約 0.97MB 減)。詳しくは
doc/progress.md の v39 記録。

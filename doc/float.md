# 浮動小数点の設計検討 (2026-11-19、実装はまだしない)

doc/missing-features.md で「別枠」に置いてきた
浮動小数点について、「やるならこうなるだろう」
を先に設計として固めるためのメモ。実需が出た
ときに独立した大版として着手する前提で、
決定事項と切り捨てと一番重い部分を明らかに
しておく。本文書は検討であり、実装の合図では
ない。

## 前提

- K210 は RV64GC で、F (単精度) と D (倍精度)
  のハードウェア FPU を持つ。ソフトウェア
  エミュレーションは採らない。
- OS 側の受け口 (FPU 有効化と fcsr 初期化) は
  用意済みと doc/missing-features.md にある。
  実機 K210 の FPU の癖 (NaN の扱い等) は
  実装時に fptest 系で実測して確かめる。
- iwac の自己ホストが硬い制約になる: コンパイラ
  自身のソースは整数演算だけで書けなければ
  ならず、浮動小数点の処理系 (特にリテラルの
  変換) は「コンパイラの中で整数として」実装
  することになる。

## 決定事項 (案)

1. **ハードウェア FP を使う**。命令は fadd.d 等
   の D 拡張 (段1) が中心。
2. **段1 は double のみ**。理由: iwac の
   スロットは一律8バイトで double と一致し、
   値の受け渡しが素直になる。float (4バイト)
   はロード/ストアの幅、float↔double 変換、
   レジスタ内の NaN boxing といった別の注意が
   増えるので段2に分ける。
3. **値の置き場**: 式評価の「現在の値」は整数が
   t1 なのと対に、浮動小数点は ft0 に置く。
   作業用は ft1 (t2 と対)。生成コードの骨格
   (二項演算で左辺をスタックに退避する形) は
   そのまま使い、退避は fsd / fld で行う。
4. **呼び出し規約は既存の形を壊さない**。
   引数の並び (a レジスタ + 16バイト間隔の
   引数領域) はそのままで、double 引数は
   ビットパターンとして整数レジスタを通す
   (境界で fmv.d.x / fmv.x.d を挟む)。戻り値も
   同じくビットとして a0 → t1 の既存経路に
   乗せ、受け側で ft0 へ移す。浮動小数点
   レジスタを引数に使う C の ABI (fa レジスタ)
   とは違うが、iwac の ABI は元々独自なので
   一貫性は保てる。

## 型の表現

- etype に浮動小数点ビット (+64) を足す。
  今の etype は 大きさ (1/2/4/8) + 符号なし
  (16) + 幅つき (32) なので、空いている。
  double = 8 + 64、float (段2) = 4 + 64。
- 型の語彙に double (段2で float) を足す。
  typedef double real; のような使い方も
  既存の typedef の仕組みにそのまま乗る。
- sizeof(double) = 8 は etype の大きさから
  自然に出る。構造体のメンバに double を
  許す: レイアウトは大きさ = 配置境界という
  v37 の C 互換規則のままで 8 バイト配置に
  なり、値セマンティクス (v45) のコピーは
  バイト単位なので無変更で動く。

## リテラル — ここが一番重い

- 字句: 数字の並びに '.' か指数部 (e / E) が
  続いたら浮動小数点リテラルとする。ノード
  には double のビットパターンを node_val に
  入れて運ぶ (整数リテラルと同じ入れ物)。
  生成時は既存の64ビット即値ロードで t1 に
  ビットを入れ、fmv.d.x で ft0 へ移す。
- **10進文字列 → IEEE 754 ビットの変換を、
  iwac 自身のソースの中で整数演算だけで
  書かなければならない**。ホストの strtod は
  自己ホスト側 (OS 上の iwac) に無いし、
  ホストと実機で変換結果が1ビットでも違うと
  固定点 (digest 一致) が崩れる。正確な
  (正しく丸める) 変換は多ワード整数の
  スケーリングで書けるが、それなりの量
  (目安として数百行ではなく百行級) になる。
  コード生成よりこちらの方が重い、という
  のがこの設計の正直な見立て。
- 切り捨て (段1): '.' から始まる形 (.5) は
  受けない (メンバアクセスの '.' と字句が
  衝突するため、数字の前置を必須にする)。
  16進浮動小数点 (0x1.8p3) も受けない。

## 演算・比較・変換

- 四則: + - * / は fadd.d / fsub.d / fmul.d /
  fdiv.d。単項マイナスは fneg.d。% と
  ビット演算・シフトを浮動小数点に適用したら
  エラー (C と同じ)。
- 比較: feq.d / flt.d / fle.d が整数 0/1 を
  返すので、結果はそのまま t1 の世界 (条件
  分岐や if の既存経路) に戻る。> と >= は
  被演算子を入れ替えて flt / fle で表す。
- 混合演算の昇格: 片方が double なら double
  に揃える (整数側は fcvt.d.l / fcvt.d.lu、
  符号は etype の符号なしビットで選ぶ)。
  段2で float が入ったら「double があれば
  double、無ければ float」の C の通常変換に
  広げる。
- キャスト: double → 整数は fcvt.l.d
  (切り捨て、C の意味どおり)。範囲外と NaN の
  振る舞いは RISC-V の飽和 semantics
  (最大/最小値に張り付き、NaN は 0) を
  iwac の仕様として採用する (C では未定義
  だが、決定的な方がこのコンパイラには合う)。
  整数 → double は fcvt.d.l / fcvt.d.lu。
- 丸めは fcsr のデフォルト (最近接偶数) の
  まま触らない。除算ゼロ等は例外でなく
  Inf / NaN が返る (IEEE の通常動作)。

## 符号化と Asari

- 命令列に浮動小数点の命令種を足す
  (fadd.d 等の R 形式、fld / fsd の I / S
  形式、fmv と fcvt)。レジスタ番号は既存の
  rd / rs の欄に浮動小数点レジスタ番号を
  入れ、命令種で区別する。分岐緩和には
  無関係 (新しい分岐は増えない)。
- .ias にも同じ命令種が要るので Asari 側も
  対応する (物差し: Asari のオブジェクトが
  iwac の符号化とバイト一致)。nori は
  リロケーションの種類が増えないので
  無変更の見込み。

## 切り捨て (段1)

- float 型 (段2送り)。
- 浮動小数点の配列初期化子 (初期値プールは
  int32 の世界なので別途の設計が要る)。
  実行時に代入すれば書ける。
- switch の case ラベルと定数式 (eval_const
  は整数専用のまま、浮動小数点はエラー)。
- 数学関数 (sin 等) は言語でなくライブラリ
  の話。やるなら libdashi の外に浮動小数点用
  の束を足す形で、言語とは分ける。
- 表示: ds_putdec のような整数の表示しか
  無いので、double を文字列にする変換
  (ライブラリ側) が無いと計算結果を目で
  確かめにくい。検証はビットパターンを
  整数として出す方法で足りるが、実用には
  表示変換が後続で要る。

## 自己ホストと容量への影響

- iwac 自身のソースは浮動小数点を使わない
  ので、新機能のコードは全部「整数として」
  書ける (変換ルーチン含む)。digest は
  ソースが増える分だけ変わるが、固定点の
  仕組み自体は影響を受けない。
- 増える場所: 字句とリテラル変換 (05-input /
  06-preproc 周辺)、型と式の検査 (02-parse /
  02b-decl)、生成 (03-gen)、符号化
  (04-encode) と Asari。容量は --stats で
  実測しながら (特に命令数の余りが細い)。

## 検証計画 (実装時)

- 裸 QEMU の check_tail で、既知の計算結果を
  ビットパターン (16進) として出力して比べる。
- リテラル変換の正確さ: 代表的な文字列の
  束について、ホストの strtod の結果ビットと
  全数一致を確かめる (変換だけ切り出した
  テストで)。
- 混合演算・キャスト・比較で分岐する
  プログラム、double を引数と戻り値にする
  関数、double メンバを持つ構造体の
  受け渡し。
- 実機: OS 側 fptest の実績があるとはいえ、
  K210 の FPU で生成コードがそのまま動くか
  は実機確認が要る (段4 の教訓: virt と
  実機は別物)。

## 段立て

- 段1: double のみ。リテラル (正確変換)、
  変数と配列、四則と比較、整数との変換と
  混合演算、関数の引数と戻り値、構造体
  メンバ。
- 段2 (必要が出たら): float、浮動小数点の
  配列初期化子、表示変換と数学関数の
  ライブラリ。
